# OS Algorithms in Java 💻  
*Operating System Algorithms Implementation*

This repository contains various Operating System algorithms implemented in Java, including CPU Scheduling, Page Replacement, and Memory Management. These algorithms demonstrate key concepts in OS design and are useful for students and professionals looking to understand the inner workings of modern operating systems.

---

## 🚀 Features

- 🖥 **CPU Scheduling Algorithms**: Implementations of algorithms like Round Robin, FCFS, SJF, and Priority Scheduling.
- 🗂 **Page Replacement Algorithms**: Implementations of algorithms such as FIFO, LRU, and Optimal Page Replacement.
- 💾 **Memory Management Algorithms**: Algorithms like First Fit, Best Fit, and Worst Fit for memory allocation.

---

## 🛠 Tech Stack

- **Java**: Programming language used for implementing the algorithms.
- **Eclipse/IntelliJ IDEA**: IDEs for development and testing.
